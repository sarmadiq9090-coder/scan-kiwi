# Code of conduct / مدونة السلوك

## عربي

يتبنى هذا المشروع **ميثاق المساهمين (Contributor Covenant) الإصدار 2.1**.
باختصار: نحترم الجميع بلا تمييز، ونتحاور بلطف ونقبل النقد البنّاء، ولا نقبل التحرش أو الإهانة أو نشر بيانات الآخرين الخاصة.
النص الكامل: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

للإبلاغ عن سلوك غير لائق: `support@fastkiwi.app`. نتعامل مع كل بلاغ بسرية.

## English

This project adopts the **Contributor Covenant, version 2.1**.
In short: treat everyone with respect, without discrimination; be kind and accept constructive criticism; harassment,
insults and publishing other people's private information are not accepted.
Full text: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

Report unacceptable behaviour to `support@fastkiwi.app`. All reports are handled confidentially.
Enforcement follows the Contributor Covenant's community impact guidelines (correction, warning, temporary ban,
permanent ban).
